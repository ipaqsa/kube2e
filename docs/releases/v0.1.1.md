# kube2e v0.1.1

Release date: 2026-06-15

This release focuses on **reporting** and **graceful shutdown**: reports now carry
human-readable timings and object-operation counts at every level, and the CLI
finally handles `Ctrl+C` cleanly instead of leaking applied resources.

## Highlights

- ⏱️ **Human-readable durations** in report files (`1m30s` instead of raw nanoseconds).
- 📊 **Object stats** per step, case, and test — how many objects were ensured, patched, and deleted.
- 🛑 **Graceful shutdown** on `Ctrl+C` (`SIGINT`/`SIGTERM`) with proper resource cleanup.

## Features

### Human-readable durations

Every `duration` field in a report now serializes as a human-readable string
(for example `1.5s`, `1m30s`, `500ms`) instead of an integer nanosecond count.

Durations are also now reported at **every level** of the report tree, not just
the top-level and per-test summaries:

| Level | Before | After |
|-------|--------|-------|
| Overall run | nanoseconds | `duration: 1m12s` |
| Test | nanoseconds | `duration: 18s` |
| Case | — | `duration: 4.2s` |
| Step | — | `duration: 900ms` |
| Action | — | `duration: 120ms` |

### Per-case and per-test object stats

Reports now include a `stats` block at the step, case, and test levels counting
the cluster objects touched by **successful** operations:

```yaml
tests:
  - name: webapp
    stats: { ensured: 3, patched: 1, deleted: 3 }   # rolled up from all cases
    cases:
      - name: deploy
        stats: { ensured: 3, patched: 1, deleted: 3 }   # steps + beforeEach/afterEach hooks
        steps:
          - name: configure
            stats: { ensured: 1, patched: 0, deleted: 0 }
```

Notes:

- Counts reflect operations that **succeeded** — a failed `ensure` is not counted.
- Case totals include objects touched by `beforeEach` / `afterEach` hooks.
- Counts cover explicit `ensure` / `patch` / `delete` actions. Objects removed by
  the post-case applied-resource cleanup are not counted as `deleted`.

### Graceful shutdown on interrupt

Pressing `Ctrl+C` (or sending `SIGTERM`) now cancels the run context so execution
unwinds cleanly:

- In-flight `wait`, `logs`, and `exec` operations stop promptly instead of being killed mid-call.
- Parallel suites (`-n`) stop dispatching new work.
- Per-case **cleanup still runs** and deletes applied resources, even though the
  run context was canceled (cleanup runs on a detached context with a 30s budget).
- A **second** `Ctrl+C` restores default behavior and force-quits.

## ⚠️ Output contract change

The `duration` fields in report files changed type from **integer nanoseconds**
to a **duration string** (`"1m30s"`). If you have tooling that parses report files
and reads `duration` as a number, update it to parse the string form
(e.g. Go's `time.ParseDuration`). The new `stats` and lower-level `duration`
fields are additive.

## Examples & docs

- Expanded the `webapp` example with `deploy`, `rollout`, and `selector` cases
  (multi-object suites, `match: all`, kind + label-selector targets).
- Added a `patch-ops` case to the `configmap` example covering the full RFC 6902 op set.
- README and `docs/` updated to match.

## Install

### Binaries

Download from the release assets and verify the checksum:

- `kube2e-linux-amd64`
- `kube2e-linux-arm64`
- `kube2e-darwin-arm64`

```bash
sha256sum -c kube2e-linux-amd64.sha256
```

### Container image

```bash
docker pull ghcr.io/ipaqsa/kube2e:0.1.1
```
